Direction 1

Merchant Center Native

The editor as a new screen inside Merchant Center. Operators feel zero context switch — the same nav rail, same header, same panel conventions they already know.

  • Left rail navigation matches existing MC
  • Right sidebar for component properties
  • Top context bar shows B2X / locale / draft state
  • Canvas center with click-to-select components
  • AI as a secondary panel (not front-and-center)
  • Governance locked badge on Red Zone components

Direction 2

Canvas First

Maximum canvas real estate. Toolbars float above the storefront. The editor gets out of the way — the storefront IS the editing surface. AI surfaces as a floating action button that expands to a panel.

  • Canvas fills the entire screen
  • Floating toolbar with context + publish at top
  • Property sidebar appears on right when element selected
  • AI chat as floating button → expands to bottom drawer
  • Figma-like feel: the design tool disappears
  • Best for experienced operators who want immersion

Direction 3

Split Studio

Lovable-inspired. AI conversation on the left, live storefront canvas on the right. The AI is the primary creation surface — operators describe, and watch changes materialize in real time.

  • Left panel: AI chat + context controls
  • Right panel: live storefront canvas
  • AI reasoning appears before applying changes
  • Conversation history = undo history
  • Direct edit available by clicking canvas
  • Best for AI-first creation workflows

Direction 4

Command Center

Dark-mode, power-user focused. AI is invoked via a command palette (⌘K). Dense information. For experienced operators who want maximum efficiency with minimal UI chrome.

  • Dark theme extending MC's enterprise feel
  • AI via ⌘K command palette — not always visible
  • Canvas shown with a subtle inset border
  • Maximum keyboard operability
  • Dense sidebar with compact property controls
  • Best for CRO and data-fluent power users

Direction 5

Context Dashboard

All B2X contexts visible simultaneously in a left panel. Click to activate a context and edit it. Designed for multi-market operators managing B2B, B2C, and multiple locales at once.

  • Left panel lists all live contexts with status
  • Canvas shows active context, click to switch
  • Each context shows its own live/draft state
  • Multi-market operators see their full scope at once
  • Best for Segment 4 (Multi-Brand B2C Enterprise)
  • Reinforces the B2X moat visually

Direction 6

Guided Creation

Step-by-step left panel guides operators through creating a new page or section. AI generates at each step based on inputs. Designed for onboarding and new-page creation flows.

  • Left panel: wizard with clear step progress
  • AI generates preview as operator fills in details
  • Right panel: live canvas preview updating in real time
  • "Generating…" state visible and non-anxious
  • Best for first-time use and new page creation
  • Transitions to Direction 1 after initial creation
