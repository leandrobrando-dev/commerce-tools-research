Design Notes

  • Three paths mapped 1:1 to FR35 — Frontastic, Custom Next.js, Monolith. Named explicitly so operators find their stack fast. (FR35)
  • Phase tags on each card — Frontastic = Phase 1B (ships first), Custom Next.js + Monolith = Phase 1C (deferrable). Developers see what's available now vs. later.
  • Effort framed in time, not component count — "1–3 hours / 1–3 days / 2–8 weeks" sets expectations developers can plan against.
  • CWV baseline is a separate affordance, not buried — the pre-sales tool is a CTA on the path selection screen itself. (FR38)
  • Path card badges tell the story — "Fastest" / "AI-assisted" / "Full migration" — one-word positioning.
  • Selected state uses AI violet wash — reinforces that AI is doing the heavy lifting on the chosen Custom Next.js path.
  • Five-step progress from the start — developers see the full arc: choose, connect, map, review, readiness.

Design Notes

  • Two-sided connection layout — source (GitHub) on the left, destination (CT project + library + API creds) on the right. Developers see both halves of the bridge before committing. (FR34)
  • Path scoping is explicit — AI only sees /src/components, /src/pages, /src/layouts. Addresses enterprise security review without friction.

Design Notes

  • Confidence tiers gate effort — high (auto), medium (review), none (manual). Developers know exactly where to spend their time. (FR35, FR36)
  • AI reasoning card names its algorithm — "40% name + 35% structure + 25% props." Transparency about how confidence is computed builds enterprise trust.
  • Green/Red Zone scaffolding is automatic — pricing, auth, checkout routed to Red Zone without prompting. Developers see the protection, not a question to answer.
  • Consolidation spotted inline — two source components mapping to one destination ("Testimonial + TestimonialList → TestimonialsCarousel") is surfaced as AI-suggested cleanup.
  • "No match" offered as a positive action — "build as new Green Zone component" — not a failure, but a path forward. FR35 accommodates custom components.
  • Export mapping CSV — lets developers review offline, share with architecture review. Standard enterprise courtesy.
  • Summary cards color-coded to match row rows — green/amber/red on the summary above maps to the row backgrounds below. Consistent visual grammar.

Design Notes

  • CWV baseline stands alone — the entire surface works without a provisioned CT project. Sales teams can hand a URL to procurement before the account exists. (FR38)
  • Before/after framing is the whole story — struck-through before, bold after, percentage delta. ROI is visceral, not buried in a table.
  • Six metrics not four — LCP, CLS, INP (the Google three) plus TTFB, FCP, TBT for engineers. Business audience looks at the three; devs look at all six.
  • Business impact projection is clearly hedged — cites Google/Deloitte benchmark, names the post-launch Horizon 2 validation path. Not an over-promise.
  • Shareable link + PDF — procurement needs a PDF; sales teams want a URL they can paste into an email. Both offered, no Figma-to-PDF export dance.
  • TBT is amber intentionally — still-blocking 3rd party named ("Hotjar"). Shows the tool is honest, not just a marketing page.
  • Gradient header matches doc header — the scorecard is branded as a first-class artifact, not a generated PDF export.

Design Notes

  • Blocker vs warning is an explicit contract — blockers fail go-live, warnings require sign-off but don't block. Governance reduced to a single actionable status. (FR39)
  • Readiness score is aggregate — 87% with 2 blockers and 3 warnings. One number for leadership, full detail for the Storefront Developer.
  • Each check names its FR + NFR — traceable back to spec. Compliance audits can cross-reference directly from the report.
  • Four check categories — Governance & coverage / Performance & a11y / Data continuity / Launch plan. Each answers a different stakeholder (architect / QA / analytics lead / ops).
  • "Estimated fix time" upfront — "~2–4 hours developer work" lets developers plan the go-live window.
  • Go live button is disabled + labeled — "(blocked)" on the button copy itself. Nothing hidden; developers know why they can't click.
  • Legacy ACI gap framed honestly — "4-hour behavioral data gap, shows as muted band for 30 days." Sets expectations about Horizon 1 charts post-cutover.
  • SEO redirects spotted automatically — 14 legacy URL mappings suggested. Migration isn't just components; it's search equity.
Wireframes are intentionally low-fidelity — dashed borders and placeholder content indicate where customer-brand content or migrated source structure will render. Final visual styling inherits commercetools Merchant Center design tokens. AI-authored surfaces use the violet-wash treatment exclusively; Red Zone stays muted neutral, draft stays amber, live stays green.
