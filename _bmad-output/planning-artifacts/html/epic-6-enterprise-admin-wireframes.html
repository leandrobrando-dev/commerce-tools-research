1 — SSO & SCIM Configuration

Enterprise identity integration is the first thing an IT Admin touches after activation. Epic 1 ships basic SAML/OIDC; Epic 6 full adds SCIM 2.0 automated lifecycle, group-to-role mapping, and a full audit log of provisioning events. IT Admins are comfortable with console-style density — metadata URLs, entity IDs, and endpoint paths are shown in monospace so they can be copy/pasted into the upstream IdP without ambiguity.

Design Notes

  • Four preset tiles + custom — covers ~90% of enterprise IdP market; custom option never hidden. Click to switch, doesn't require wizard progression. (FR40)
  • Monospace for every identifier — SAML entity IDs, ACS URLs, Name ID formats are copy/pasted into the IdP; visual ambiguity (O vs 0, l vs 1) breaks integrations.
  • Residency chip in topbar — "🌍 EU · Frankfurt" is always visible. Every endpoint URL reflects the active region — IT Admin never needs to translate between regions. (FR44)
  • Status dot in sidebar — grey = not configured, green = healthy, amber = warning. IT Admin scans left rail for what's outstanding. (FR42)
  • Dev-frame density — denser padding and monospace data rows; console aesthetic IT Admins trust.
  • Copy-all-as-JSON button — some orgs automate IdP config via Terraform/Pulumi; single-blob copy makes that trivial.

Design Notes

  • Success-soft banner, not alert — green-tinted card confirms SSO is live with verification timestamp and concrete evidence ("14 users signed in last 7 days"). IT Admin trusts what they can measure. (FR40)
  • Attribute mapping is a table, not a form — dense, scannable, exactly what IT Admins expect from identity tooling. (FR42)

Design Notes

  • SCIM endpoint details shown in monospace — base URL, bearer token, filter predicates. IT Admins pipeline this into Okta's provisioning form. (FR41)
  • Token expiry shown green/amber/red — 90-day rotation surfaced as "89 days" reminder. Prevents surprise auth failures.
  • Lifecycle events taxonomy — Provisioned / Updated / Deprovisioned / Group push / Manual override. Each color-coded so auditors scan by event class.
  • Deprovision event names concrete consequence — "sessions terminated in 8s · 3 in-flight drafts preserved, assigned to manager" — no orphan work, no data loss, no ambiguity about what happened.
  • Human and SCIM actors coexist — Okta SCIM bot and human IT Admin both appear with distinct avatars (Epic 3 pattern reused). Manual overrides are first-class events, not exceptions.
  • Immutable, 7-year retention — pill in the section header makes the compliance promise visible. CSV export for SOC 2 / ISO 27001 evidence collection.
  • Summary chips at top-right — provisions / deprovisions / updates counts give auditors an instant sense of activity shape.

2 — Multi-Brand Access Boundaries & Data Residency

Multi-brand B2C enterprises (e.g. Acme Group managing Vento, Luma, Nova storefronts) need access boundaries per brand, per environment. Meanwhile, every tenant must choose EU or US data residency at activation — it's visible as an immutable fact for the life of the tenant. The residency decision drives which CT project, which ClickHouse cluster, which region-locked services handle their data.

Design Notes

  • Residency is Step 2 of activation — not buried in settings. Without this choice, the tenant cannot be provisioned at all. (FR44)
  • "Cannot be changed after activation" warning in sub-bar — visible before the user commits, not after. Prevents the most common enterprise support ticket ("can we move to EU?").
  • Side-by-side region cards — same structure, both showing sub-processors, DR region, compliance claims, and the exact data categories that live in-region. No surprises at audit time.
  • Phase-2 regions shown muted — UK and APAC regions visible but disabled. Signals roadmap; gives IT Admin confidence the vendor is growing with them.
  • Selected region highlighted with success green — consistent with the "good state" signal language across Epic 6.
  • Interactive pins — click EU or US pin to see selection state change. Reinforces that this is a deliberate choice, not a default.

Between Acme Global GmbH ("Controller") and commercetools GmbH ("Processor") — pursuant to GDPR Article 28

1. Subject matter and duration

This Addendum governs the processing of personal data by commercetools GmbH on behalf of Acme Global GmbH in connection with the commercetools Next-Gen Frontend platform (the "Services"), activated on 2026-03-14. This Addendum remains in force for the duration of the underlying Services Agreement.

2. Nature and purpose of processing

The Processor will process personal data to provide the Services, including: authenticating users via SSO (SAML 2.0/OIDC); provisioning user lifecycle state via SCIM 2.0; capturing behavioral event streams to power the AI Experience Engine; generating AI-assisted storefront content; and retaining audit logs for compliance evidence.

3. Categories of data subjects and personal data

Data subjects: Controller's employees, contractors, and end-consumers of the Controller's storefronts. Categories: identity claims (name, email, group membership); session identifiers and behavioral event metadata; IP addresses (truncated for GDPR); AI prompt/completion transcripts (operator-generated).

All personal data will be stored and processed within the European Union (eu-central-1 / Frankfurt), with disaster recovery replication to eu-west-1 (Ireland). No personal data will be transferred to non-EU jurisdictions without a prior written amendment to this Addendum.

The Processor maintains the technical and organisational measures described in Annex B, including: SOC 2 Type II certification; ISO 27001 certification; encryption in transit (TLS 1.3+) and at rest (AES-256); role-based access control via CASL; immutable audit logs retained for 7 years; and annual penetration testing.

7. Audit rights and term

The Controller may audit the Processor's compliance with this Addendum on 30 days' written notice, no more than once per calendar year, subject to reasonable confidentiality undertakings. This Addendum automatically renews with the underlying Services Agreement.
